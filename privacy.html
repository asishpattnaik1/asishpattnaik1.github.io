Privacy policy

Last updated: 9 October 2026

learnaiwithasish publisher ("the app") is a personal tool run by Asish Pattnaik to publish his own videos. It is used only with his own accounts.

What the app accesses

When Asish signs in with Google, the app requests permission to upload videos and to manage the videos, thumbnails, captions and playlists on his YouTube channel, through the YouTube API Services. On Instagram it uses an access token for his own professional account to publish his reels.

What is stored, and where

The sign-in tokens are stored only on Asish's own computer, in a private folder. The app has no server and no database. It does not collect, sell or share data about anyone, and it does not access other people's accounts or data.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google security settings page: myaccount.google.com/connections. Deleting the token files on the computer also removes the app's access.
